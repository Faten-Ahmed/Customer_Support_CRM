# US-BE-079 — Report Export (CSV / Excel / PDF)

## Technology Requirements

**Frontend (if applicable):**
- **UI Framework:** Angular Material ONLY (NOT Tailwind, NOT Bootstrap)
- **RTL/LTR:** Must support both RTL (Arabic) and LTR (English)
- **Arabic:** All user-facing text must be translatable to Arabic
- **English:** All user-facing text must be in English
- **i18n:** Use Angular's built-in i18n (`@angular/localize`)

**Backend (if applicable):**
- **Framework:** .NET 10, C#
- **API:** RESTful with OpenAPI
- **Language:** C# with Arabic/English string resources

---


**Epic:** Reports & Dashboard
**Roles:** Admin, Manager
**As a** manager, **I want to** export reports to CSV, Excel, or PDF, **so that** I can share them with stakeholders outside the CRM.

## Acceptance Criteria
- [ ] `GET /reports/export?reportType=tickets|sla|agents|csat&format=csv|xlsx|pdf&dateFrom=&dateTo=` returns the file synchronously for datasets ≤ 10,000 rows
- [ ] Agent role returns `403`
- [ ] For > 10,000 rows: returns `202 Accepted` with `{ "jobId": "..." }`; file generated by Hangfire; client polls status endpoint
- [ ] Content-Type and Content-Disposition headers set correctly per format
- [ ] Role scoping same as corresponding JSON report
- [ ] PDF includes: company logo, report title, date range, generated-at timestamp, data tables (no charts)

## Technical Notes
- Endpoint: `GET /reports/export`
- Libraries: `CsvHelper` (CSV), `ClosedXML` (xlsx), `QuestPDF` or `PdfPig` (PDF)
- Business rules: BR-RPT-015—018
- Spec: `specs/api/reports.md`

## Dependencies
